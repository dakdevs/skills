# iPhone Review Gate

## Focus and Navigation

- [ ] The primary task/content is visible before secondary controls.
- [ ] Tabs represent a small stable set of peer destinations.
- [ ] Hierarchical drill-in has a predictable back path.
- [ ] Sheets have explicit save/cancel/dismissal and unsaved-work behavior.
- [ ] Alerts are rare and reserved for attention-worthy decisions.

## Touch and Reach

- [ ] Routine interactive regions meet the 44x44 pt default target where applicable.
- [ ] Controls have enough separation to prevent accidental activation.
- [ ] Frequent actions are comfortably reachable or have a reachable alternative.
- [ ] Every essential gesture has a visible control alternative.
- [ ] Pressed, disabled, selected, progress, and error states are clear.

## Adaptability

- [ ] Safe areas, Dynamic Island/camera housing, corner radius, and overlaying controls are respected.
- [ ] Portrait and landscape work when supported; both landscape rotations are tested.
- [ ] Dynamic Type through accessibility sizes reflows without losing primary content or actions.
- [ ] Dark Mode, Increase Contrast, Reduce Motion, RTL, and VoiceOver are tested.
- [ ] Status bar is hidden only for a meaningful immersive reason.

## Interruption and Data

- [ ] Backgrounding, app switching, calls, authentication, and network failure preserve the task.
- [ ] Forms use appropriate keyboards, persistent labels, inline correction, and draft preservation.
- [ ] Permissions occur at the feature moment and denial leaves unrelated capability usable.
- [ ] Loading, empty, offline, error, denied, success, and restored states are intentional.
- [ ] Destructive action uses the correct role, separated placement, and undo/confirmation.

## Evidence

Record device(s), orientation, Dynamic Type size, touch/reach behavior, VoiceOver, appearance,
interruption cases, network/authentication states, and results.
