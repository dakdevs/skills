# Design Review Gate

Fail the gate when a primary task, state, or hierarchy problem remains.

## Product

- [ ] Primary person, job, object, and success are clear
- [ ] First vertical slice supports the primary loop
- [ ] Non-goals prevent accidental scope
- [ ] Sensitive/destructive operations are explicit

## Information Architecture

- [ ] Top-level destinations are stable peer contexts
- [ ] Navigation depth matches the content relationship
- [ ] Sheets are temporary tasks
- [ ] Search uses a system pattern
- [ ] Back/cancel/undo behavior is clear

## States

- [ ] Initial/loading/empty/populated/error states exist where relevant
- [ ] Offline/permission/destructive states exist where relevant
- [ ] Empty and error states provide a next action
- [ ] User input survives recoverable failures

## Hierarchy and Content

- [ ] One primary action is evident
- [ ] Typography survives without color
- [ ] Copy is specific and actionable
- [ ] Fixtures are realistic
- [ ] Long content and large text work

## Adaptation

- [ ] Narrow and wide layouts were inspected
- [ ] iPad gains useful context rather than blank margins
- [ ] Safe areas and keyboard are respected
- [ ] Last scroll content remains reachable

## Platform

- [ ] System components are used by default
- [ ] Custom interactions have a product reason
- [ ] Visual identity does not replace native behavior
- [ ] Liquid Glass remains in the functional layer

## Evidence

Record preview/runtime states used and unresolved product decisions.
