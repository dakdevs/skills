# Accessibility Review Gate

## Semantics

- [ ] Controls expose correct labels and roles
- [ ] Selected/toggled/current values are announced
- [ ] Decorative images are hidden
- [ ] Complex visuals have useful representations
- [ ] Reading and focus order match the task

## Text and Layout

- [ ] Semantic text styles are used
- [ ] Accessibility sizes do not clip
- [ ] Controls remain reachable with large text
- [ ] Bold Text does not break hierarchy
- [ ] Long localized strings work
- [ ] Right-to-left layout is coherent

## Perception

- [ ] Meaning is not color-only
- [ ] Light/dark and Increased Contrast were tested
- [ ] Reduce Transparency was tested
- [ ] Glass remains legible across backgrounds
- [ ] Status/error/success has text or semantic feedback

## Motion and Input

- [ ] Reduce Motion path preserves meaning
- [ ] Animations can be interrupted
- [ ] Gestures have accessible alternatives
- [ ] Interaction areas are comfortable
- [ ] Keyboard/pointer path works when relevant
- [ ] Haptics are supplemental

## Privacy and Permissions

- [ ] Permission request follows an explanation of value
- [ ] Denial has a useful recovery/alternative
- [ ] Sensitive data is absent from fixtures/logs/screenshots
- [ ] Destructive/sharing consequences are clear

## Evidence

List actual settings, devices/simulators, screens, and flows inspected. Fail when the report only
says "native controls used."
