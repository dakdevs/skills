# Dmgly

URL: [dmgly.com](https://dmgly.com/)

Status: saved.

## Use when

- Designing a background and layout for a macOS DMG installer.
- Polishing app distribution with a branded installation window.
- Preparing DMG packaging configuration for Electron, Tauri, or Swift/macOS.

Search terms: macOS, DMG, disk image, installer, background, layout, app packaging, Electron, electron-builder, Tauri, Swift.

## Access

Browser-based editor at the URL above. Its export UI offers Electron, Tauri, and Swift/macOS targets, with Configuration and AI prompt options. The Electron configuration preview uses the filename `electron-builder.dmg.json`.

## Workflow

1. Open the editor and design the DMG background and installation layout for the app.
2. Choose the project's target platform in the export UI.
3. Inspect the generated configuration. Use Copy config or Download ZIP to obtain the output.
4. Integrate the output into the project's existing packaging setup and build a DMG to check the result.
